| `de-anca-2025-idb-latam-ee.md` | Adaptación del modelo Isenberg al **sector cuidados en LatAm**. Secuenciación de 5 pasos para desarrollo de ecosistemas. Barreras LatAm específicas. |
| `macke-2020-community-building-framework.md` | **Evolución de Programas a Sistemas** (40 años de experiencia). 5 tipos de emprendedores. La "transacción básica" centrada en el emprendedor. NetWork Kansas como caso. |

| `kreuzer-2018-giz-ecosystem-mapping.md` | **Scorecard de benchmark** para tracking longitudinal. 5 métodos de visualización diagnóstica. Indicadores de desempeño para monitoreo. |
| `audretsch-2019-ecosystem-impacts.md` | **El problema de las fronteras** en investigación de ecosistemas. No se puede capturar impacto con una sola medida agregada. |
| `foster-2013-wef-ee-growth.md` | **Datos de percepción de 1,000+ emprendedores** en 43 países. Datos específicos de México. Concentración extrema de resultados (breakout companies). |
| `wild-2023-ilo-ee-development.md` | **7 deficiencias comunes de diagnósticos EED**. 5 deficiencias comunes de medición. Framework de auto-evaluación de "systemsiness". |
| `meyers-2015-making-measuring-ecosystem.md` | **Dashboard de 5 métricas**. Diferentes métricas por etapa de ecosistema. Métricas de fortaleza de red. Progresión de madurez en 4 etapas. |
